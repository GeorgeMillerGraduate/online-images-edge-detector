About the filters & transitions

Filter changes prepare a new edge map and reset the reveal to the original photograph. The scan order changes only how that map appears; it never changes the computed edges. Images are processed at a maximum longest side of 960 pixels.

Centre–surround uses a normalised circular disc minus a surrounding annulus. ON detects a brighter centre, OFF a darker centre, and Both uses the absolute response. This is a simple retina-inspired contrast operator, not a circular shape detector.

All ten scan priorities are adapted from George Miller’s Java Mandelbrot renderer. Read the exact conventions and credits ↗
